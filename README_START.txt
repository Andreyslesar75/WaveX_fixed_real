# ФАЙЛ: README_START.txt
# Простая инструкция запуска WaveX_fixed.

====================================================
ШАГ 1. Установи Python
====================================================

Если у тебя Windows:

1. Зайди на официальный сайт Python:
   https://www.python.org/downloads/

2. Скачай Python 3.10 или 3.11.

3. При установке ОБЯЗАТЕЛЬНО поставь галочку:
   "Add Python to PATH"

4. После установки перезагрузи компьютер, если нужно.


====================================================
ШАГ 2. Создай папку проекта
====================================================

Создай папку, например:

C:\WaveX_fixed

Положи в неё все файлы бота:

main.py
config.py
logger.py
database.py
api.py
calculations.py
signals.py
scanner.py
risk_manager.py
ws_client.py
gui.py
requirements.txt
.env.example


====================================================
ШАГ 3. Открой терминал в папке проекта
====================================================

Windows:

1. Открой папку WaveX_fixed.
2. Нажми на адресную строку сверху.
3. Напиши: cmd
4. Нажми Enter.

Откроется командная строка уже в нужной папке.


====================================================
ШАГ 4. Создай виртуальное окружение
====================================================

В командной строке напиши:

python -m venv venv

Потом активируй его:

venv\Scripts\activate

Если всё получилось, слева появится:

(venv)


====================================================
ШАГ 5. Установи библиотеки
====================================================

Напиши:

python -m pip install --upgrade pip

Потом:

pip install -r requirements.txt


====================================================
ШАГ 6. Создай файл .env
====================================================

Скопируй файл:

.env.example

в новый файл:

.env

В Windows можно сделать так:

copy .env.example .env

Пока НЕ вставляй туда реальные API ключи.
Оставь:

REAL_TRADING=false


====================================================
ШАГ 7. Запуск бота
====================================================

Если хочешь запуск с GUI:

python main.py

Если GUI не открывается или мешает:

python main.py --headless


====================================================
ОЧЕНЬ ВАЖНО
====================================================

Сначала используй только бумажный режим:

REAL_TRADING=false

Не включай реальные деньги, пока не проверишь:

1. Что бот стабильно работает несколько часов.
2. Что нет ошибок в логе.
3. Что сделки открываются и закрываются нормально.
4. Что стоп-лосс и TP работают правильно.
5. Что после перезапуска бот не теряет состояние.

Реальная торговля без этих проверок может привести к потере денег.
